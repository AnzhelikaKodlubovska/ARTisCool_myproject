# 🎨 ART-Platform: Платформа для конкурсів малювання

Сучасна веб-платформа для проведення художніх конкурсів, яка об’єднує талановитих учасників, професійне журі та адміністраторів. Проект побудований на стеку **React + Django**.

---

## 🛠 Технологічний стек

### Frontend (React)
* **Бібліотеки:** React 18, Tailwind CSS, Lucide React (іконки).
* **Анімації:** Framer Motion або CSS Keyframes для персонажа-помічника.
* **Особливості:** Інтерактивний асистент, що з’являється випадковим чином, адаптивна галерея робіт.

### Backend (Django)
* **Фреймворк:** Django 5.x / 6.x.
* **API:** Django REST Framework (DRF).
* **База даних:** SQLite (для розробки) / PostgreSQL.
* **Автентифікація:** Токени (drf_authtoken) для розмежування ролей.

---

## 👥 Ролі користувачів

Проект підтримує три рівні доступу:
1. **Користувач (Учасник):** Може переглядати галерею та завантажувати власні роботи на конкурс.
2. **Журі:** Має доступ до панелі оцінювання для виставлення балів та коментарів до робіт.
3. **Адмін:** Повний контроль над контентом, керування списком журі та публікація кращих робіт у загальну галерею.

---

## 🚀 Як запустити проект

Проект складається з двох частин, які мають працювати одночасно.

### 1. Запуск Backend (Django)
Відкрийте новий термінал:
```bash
cd Contest_project/Django_contest
.\venv\Scripts\activate
python manage.py migrate
python manage.py runserver
```
### 2. Запуск Frontend (React)
Відкрийте другий термінал:
```bash
cd Contest_project/React_contest/art-platform
npm install
npm run dev
```
